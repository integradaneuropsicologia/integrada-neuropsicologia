# Integrada Neuropsicologia

Site institucional da Integrada Neuropsicologia, reconstruído em Next.js/vinext com foco em clareza, conversão e acessibilidade.

## O que está incluído

- páginas de avaliação neuropsicológica por faixa etária e demanda;
- páginas de psicoterapia;
- quatro checklists educativos, sem pontuação diagnóstica;
- 20 jogos gratuitos de estimulação mental;
- blog com artigos educativos;
- formulários e CTAs integrados ao WhatsApp;
- layout responsivo e metadados para compartilhamento.

## Desenvolvimento

Requer Node.js `>=22.13.0`.

```bash
npm install
npm run dev
npm run build
```

O projeto usa a estrutura vinext fornecida pelo Sites e gera saída compatível com Cloudflare Workers.

## Aviso sobre os checklists

Os checklists do site promovem reflexão, não interpretam respostas automaticamente e não substituem avaliação clínica ou diagnóstico profissional.
